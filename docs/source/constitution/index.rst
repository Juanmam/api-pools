Constitution
============

This suite defines **semantic law**, **non-negotiable constraints**, and **dependency boundaries** for API Pools—**before** implementation encodes hidden assumptions.

**Foundational truth:** API Pools standardizes what “the same thing” means across vendors while making incompatibility **explicit and computable**.

Every chapter reinforces interoperability honesty over masking, semantic correctness over convenience, and bounded contexts over universal models.
